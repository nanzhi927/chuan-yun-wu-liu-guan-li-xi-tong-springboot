- JDK 1.8+（以 `pom.xml` 为准）

- MySQL 5.7+ / 8.x

1. 克隆本仓库
2. 用 IDE 打开项目根目录（含 `pom.xml` / `package.json`）

## ❓ 常见问题

**跑不起来？**
- 确认 JDK / Maven / MySQL 版本与运行必读一致；先能编译通过再启动。

**端口占用？**
- 修改 `server.port`，或关闭占用 8080 的进程。

**数据库连接失败？**
- 检查库名是否已创建、账号密码、时区与 `allowPublicKeyRetrieval` 等 JDBC 参数。
